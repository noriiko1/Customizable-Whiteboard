# Interactive Whiteboard for Browser

# Description:
This is a lightweight whiteboard you can use in the browser to sketch stuff.

# How to use:
Mouse and Click: Hold down the left click and drag the mouse.

Keyboard: Navigate using WASD keys and press down Enter to draw

# Extra Features:
- Line Tool: Makes straight lines
- Circle Tool: Makes circles
- Rectangle Tool: Makes rectangles
- Lasso Tool: Lets you circle a drawing and move it around the whiteboard
- Erase Tool: Lets you erase drawings

## Additional Options:
- You can change the color and size of what you want to draw.
- You can swap between a grid or blank pattern on the whiteboard.
